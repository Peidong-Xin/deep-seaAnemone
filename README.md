# Supporting Code for the Deep-Sea Anemone Study

This repository contains the command reference document and analysis scripts associated with the manuscript “**Evolutionary patterns and repeated adaptive strategies of deep-sea anemones**.” It is intended to document the computational analyses described in the STAR Methods section and to facilitate inspection and reuse of the analysis code. For questions about the study or associated materials, please contact the corresponding authors.

## Repository Contents

- `00.basic.code.docx` — A curated command reference document corresponding to the STAR Methods section. It covers sequencing-read quality control, genome and transcriptome assembly, repeat and gene annotation, gene-expression analysis, phylogenetic reconstruction, orthogroup inference, validation of recurrent gene loss, and PSMC analysis of historical population dynamics. Software versions and reported parameters are provided wherever available.
- `01.sitecheck/` — Source scripts for identifying and evaluating **deep-sea-specific amino acid variation sites** and **deep-sea-specific genes (DSGs)**.
